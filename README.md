# Validador de Campos Numéricos

Um projeto simples que compara dois valores numéricos e exibe uma mensagem indicando se o Campo B é maior que o Campo A.

## 📋 Funcionalidades

- **Validação em tempo real**: Compara os valores dos campos A e B.
- **Feedback visual**: Exibe mensagens coloridas (verde para válido, vermelho para inválido).
- **Design responsivo**: Funciona bem em dispositivos móveis e desktop.
- **Interface limpa**: Design moderno com sombras e transições suaves.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica do formulário.
- **CSS3**: Estilização com Flexbox, sombras e efeitos hover.
- **JavaScript**: Lógica de comparação e manipulação do DOM.
